REDPATH — це лендінг на тему космічного туризму. Сайт пропонує вигадані польоти на Марс і створений для людей, які цікавляться космосом та мріють про незвичайні подорожі.

JavaScript-функції:
Бургер-меню для мобільних пристроїв.
Модальне вікно з формою бронювання польоту.
Можливість збільшувати зображення космічного корабля.
